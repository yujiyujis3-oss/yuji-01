# ホームページ デザイン仕様・Claudeへの引き継ぎ

## 制作の目的
ホームページ制作・広告デザインを主力に、自動化ツール制作まで相談できる制作サービスのサイト。今回の成果物はデザイン案と実装仕様。公開用コードの制作はClaudeに引き継ぐ。

屋号・運営者名・連絡先・実績・価格は未提供。カンプの「STUDIO / NAME」は仮表記。参考サイトの松藤智明さんの氏名、経歴、実績を依頼者の情報として転用しない。

## コンセプト
「静かな未来感」。黒い展示空間に、白い機械生命体が浮かび上がる。精密さと創造性を表現しながら、サービス説明は読みやすく明快にする。

- 主役：添付1の白い外殻、黒いレンズ、露出した機構とケーブルを持つキャラクター。
- 空間表現：添付2のガラス、反射、暗い展示空間、細いスポットライト。
- デザインの優先順位：提供サービスの理解 → 制作イメージ → 相談。
- キャラクターは主にヒーローで大きく使用。背景全体を過剰なSFパネルや発光装飾で埋めない。
- ガラスの馬は主役のキャラクターと混同せず、クリエイティブ表現の参考として扱う。

## トップページ構成と文案

### 1. ヘッダー
左に屋号。右に「サービス」「制作イメージ」「制作の流れ」、CTA「制作を相談する」。高さ80px。最初はヒーローと一体化し、スクロール時は不透明に近い黒背景。

### 2. ファーストビュー
肩書き：WEB DESIGN / AD CREATIVE / AUTOMATION

見出し：
> 伝わるデザイン。
> 進化するビジネス。

説明：
> ホームページ・広告・自動化ツールを、ひとつにつなぐ。
> 見せ方から日々の運用まで、事業に合わせて設計します。

主CTA「制作を相談する」、副CTA「サービスを見る」。左に文字、右にキャラクター。キャラクターのレンズや白い外殻に文字を重ねない。背景画像を使う場合は左側に黒のグラデーションをかける。

### 3. サービス
明るいアイボリー背景に切り替え、読みやすさと画面のリズムをつくる。

見出し「つくる。その先まで。」

| 番号 | サービス | 説明文 | 補足ラベル |
|---|---|---|---|
| 01 | ホームページ制作 | 伝えたい価値が届く、使いやすいWebサイトへ。目的に合わせて構成とデザインを設計します。 | コーポレートサイト / LP / ECサイト |
| 02 | 広告デザイン | 商品やサービスの魅力を整理し、目に留まり、伝わるクリエイティブへ。 | バナー / SNS広告 / キービジュアル |
| 03 | 自動化ツール制作 | 繰り返しの作業を見直し、日々の業務に合う仕組みをつくります。 | データ整理 / 業務フロー / AI活用 |

各項目は同じ幅の3列。大きい番号、見出し、説明、細い図形の順。上記の詳細な対応範囲は提案であり、公開前に実際の対応範囲と照合する。

### 4. 制作イメージ
暗い背景に戻し、大小2枚のビジュアルを並べる。各作品に「CONCEPT / 自主制作イメージ」を明記する。

- Web方向性：透明なガラス彫刻を使ったアートギャラリー風サイト。
- 広告方向性：アイボリー地に大きな文字とシアンの細いアクセント。

これらは表現の提案であり、納品実績ではない。実際の掲載許可済み作品が用意されたら、画像・担当範囲・制作目的を差し替える。架空の顧客名や成果数値を記載しない。

### 5. 制作の流れ
01 ご相談 → 02 方向性の整理 → 03 デザイン・制作 → 04 確認・公開

横方向の細い線でつなぐ。スマートフォンは縦並び。各工程の本文は1〜2行。カンプに省略されている場合も、実装では制作イメージと相談セクションの間に配置する。

### 6. 相談セクション
見出し「次の一歩を、一緒につくる。」

説明「つくりたいものや、日々の業務の困りごとからお聞かせください。」

CTA「制作を相談する」。実装先は連絡先確定後にメールまたは問い合わせフォームを接続。確認用画面では「お問い合わせ先は準備中です」と分かる表示にし、送信成功を装わない。

### 7. フッター
正式な屋号、必要な運営情報、問い合わせ、プライバシーポリシー。未確定の住所・個人名・メールを捏造しない。

## スマートフォン仕様
390pxを基準に左右24px。ヘッダー64px。見出し34〜40px、本文16px。ファーストビューは「肩書き → 見出し → 説明 → CTA → キャラクター」の順。キャラクター画像を高さ約320pxで見せ、主要パーツを切らない。写真の上に本文を乗せない。

サービスと作品は1列。ボタンは幅いっぱい、タップ領域44px以上。メニューには開閉ボタン、閉じる操作、キーボード操作、フォーカス管理を設ける。320px〜の横幅でも横スクロールが出ないようにする。

## 動き
初回表示はテキストとビジュアルを短いフェードで表示。下層は移動距離12px以内・400〜600msの控えめな出現。ホバー時は罫線・矢印の変化のみ。本文表示をアニメーション完了に依存させない。

キャラクターは静止画像で成立させる。回転・動画・3Dは必須にしない。動きを減らす設定ではアニメーションを無効化。自動再生音、長いローディング演出、マウス追従カーソルは使用しない。
