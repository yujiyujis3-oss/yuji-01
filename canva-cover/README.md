# Canvaで作る「表紙作成」サムネイル（再現レシピ）

参考画像と同じ構成の正方形サムネイルです。

- `cover.html` … デザイン本体（ブラウザで開くと表示）
- `cover.png` … 1080×1080 の書き出し画像（Canvaにアップロードして下敷きにも使えます）

## 1. キャンバスを作る

Canvaのホーム →「デザインを作成」→「Instagramの投稿（正方形）」（1080×1080px）

## 2. 背景

- 背景色：`#F6F7F5`（ほぼ白）
- 「素材」で「水彩 背景 淡い」「グラデーション 淡い」などを検索し、薄いグレー／グリーンの素材を置いて**透明度 30〜50%**に下げる

## 3. 要素ごとの作り方

| 要素 | 作り方 | 色・フォントの目安 |
|---|---|---|
| **完全攻略**（上のラベル） | テキストを入れて「エフェクト」→「背景」。**丸み 100・広がり 大きめ**にすると角丸のラベルになる。代わりに「素材」→「図形」の角丸長方形を置いてもよい | 背景色 `#3CBCC3`／文字 白／フォント「M PLUS Rounded 1c」太字、または「Zen丸ゴシック」／「エフェクト」→「シャドウ」を薄く |
| **Canva で** | 「Canva」と「で」を別のテキストにする。「Canva」は筆記体フォントにして、グラデーションを付ける（ロゴ素材は使わない） | 筆記体フォント「Pacifico」など／グラデーション `#1FC8D8`→`#7D2AE8`／「で」は `#56565E` |
| **表紙作成**（大見出し） | テキストを入れ「エフェクト」→**「スプライス」**。太さ・オフセット・方向を調整して、線の外にずらした塗りを付ける | フォント「M PLUS Rounded 1c」極太、または「Zen丸ゴシック」Black／線 `#4A4A55`／スプライスの色 `#CF97EA`／方向 左下（約 225°） |
| **女性のイラスト** | 「素材」で「女性 パソコン デスク イラスト」「ビジネスウーマン 椅子」などを検索 | 黄色いジャケットなど、ティールと紫に合う配色のものを選ぶ |
| **吹き出し** | 「素材」で「吹き出し 線」「吹き出し シンプル」を検索。しっぽ（尖った部分）がイラストの方を向くように置く | 線 `#6B6B72`／塗り 白（透明度 50%程度） |
| **制作時間 たったの 10 分** | 「制作時間／たったの」「10」「分」の3つのテキストを別々に作って並べる | 「制作時間 たったの」「分」は手書き風の「Klee One」、`#6B6B72`／「10」は赤 `#F0463C`、細めの丸ゴシックで大きく |

## 4. 配置の目安（1080×1080 のとき）

```
┌──────────────────────────┐
│        [ 完全攻略 ]        │  ← 上から約 100px、幅 600px
│         Canva で          │  ← 上から約 260px
│                          │
│       表 紙 作 成         │  ← 上から約 430px、幅は左右ほぼいっぱい
│                          │
│  (イラスト)  ╭──────────╮  │
│   女性+PC   │制作時間 10分│  │  ← 下から約 90px
│             ╰──────────╯  │
└──────────────────────────┘
```

## 5. 仕上げ

- 「位置」→「整列」で、ラベル・Canvaで・表紙作成を**中央揃え**にする
- 右上の「共有」→「ダウンロード」→ PNG で書き出す
