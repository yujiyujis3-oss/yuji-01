# STUDIO / NAME — 制作サービスサイト（確認用）

ホームページ制作・広告デザイン・自動化ツール制作を紹介する1ページのサイトです。
デザインカンプ（`docs/design-comp.webp`）と引き継ぎ仕様書（`docs/handoff-spec.md`）をもとに、HTML / CSS / JavaScript だけで作っています（ビルド作業は不要）。

## ファイル構成

```
index.html              ページ本体（見出し・本文・ボタン・メニューはすべてHTMLで作成）
css/style.css           デザイン（配色・余白・スマートフォン対応）
js/main.js              メニューの開閉、スクロール時のヘッダー、表示アニメーション など
images/                 キャラクター・ガラスの馬の画像（720px版と1254px版）
docs/handoff-spec.md    引き継ぎ仕様書
docs/design-comp.webp   デザインカンプ（参考用。ページには使っていません）
```

## ブラウザで表示する手順

### いちばん簡単な方法
`index.html` をダブルクリックするか、Chrome / Safari / Edge にドラッグ＆ドロップすると表示されます。

### ローカルサーバーで表示する方法（おすすめ）
実際の公開環境に近い状態で確認できます。ターミナルでこのフォルダに移動して、次のどちらかを実行します。

```bash
# Python がある場合
python3 -m http.server 8000

# Node.js がある場合
npx serve .
```

ブラウザで `http://localhost:8000`（`npx serve` の場合は画面に表示されたURL）を開きます。

### スマートフォン表示の確認
Chrome でページを開き、右クリック →「検証」→ 画面左上のスマートフォンのアイコンで、320px / 390px / 768px などの幅を確認できます。

## 対応していること

- PC・タブレット・スマートフォン（320px〜、横スクロールなし）
- スマートフォンのメニュー：開閉ボタン、閉じるボタン、Escキーで閉じる、メニュー内でフォーカスが留まる、閉じた後はボタンにフォーカスが戻る
- キーボード操作とフォーカス表示、「本文へスキップ」リンク
- 動きを減らす設定（OSの「視差効果を減らす」など）ではアニメーションを止める
- 画像は縦横サイズを指定。ヒーロー以外は遅延読み込み
